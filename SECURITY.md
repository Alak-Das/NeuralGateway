# Security Policy

## Supported Versions

We provide security updates for the following versions of Neural Gateway:

| Version | Supported          |
|---------|--------------------|
| 0.0.1   | :white_check_mark: |
| < 0.0.1 | :x:                |

## Reporting a Vulnerability

To report a security vulnerability, please email the maintainers at
[security@neuralgateway.example.com](mailto:security@neuralgateway.example.com)
with the following information:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- Potential impact and severity
- Any proof-of-concept code or exploit details
- Version(s) affected

We will acknowledge receipt of your report within 48 hours and provide
regular updates on our investigation and resolution process.

## What Happens After Reporting

1. **Acknowledgment**: We'll confirm receipt of your vulnerability report
2. **Investigation**: Our team will investigate and validate the report
3. **Communication**: We'll keep you informed of our progress
4. **Resolution**: We'll develop and test a fix
5. **Disclosure**: We'll coordinate public disclosure and provide credit

## Security Best Practices

When using Neural Gateway, we recommend:

1. **Keep Dependencies Updated**: Regularly update Java, Maven, and dependencies
2. **Secure API Keys**: Store API keys securely using environment variables or secret management systems
3. **Network Security**: Deploy behind firewalls and use HTTPS in production
4. **Monitoring**: Enable logging and monitor for unusual activity
5. **Regular Audits**: Periodically review configurations and access controls
